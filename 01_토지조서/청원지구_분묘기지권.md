## 2. 용어 설명 (쉬운 말)

| 용어 | 쉬운 설명 |
| --- | --- |
| **분묘** | 땅에 있는 무덤 |
| **연고자** | 무덤과 법적·혈연적으로 연결된 사람(후손·설치자 등) |
| **유연고(유연)** | 연고자를 **알고** 있거나 **찾을 수 있는** 무덤 |
| **무연고(무연)** | 연고자를 **알 수 없는** 무덤 |
| **개장** | 무덤을 열어 유골을 옮기는 일(이장) |
| **개장신고** | 연고자와 합의한 뒤 시청·구청에 **신고**하고 이장하는 절차 |
| **개장허가** | 연고자를 모를 때 시청·구청의 **허가**를 받고 이장하는 절차 |
| **공고** | “이장할 테니 연고자는 신고하라”고 **여러 차례 공개**하는 것 |
| **분묘기지권** | 남의 땅에 오래 있던 무덤을 **함부로 치울 수 없게** 하는 관습법상 권리. 등기부에는 안 나옴 |
| **묘적부** | 시청이 관리하는 **무덤 대장**(신고·허가가 있었던 것만 있을 수 있음) |
| **신탁** | 땅을 신탁회사에 맡긴 상태. 형식상 소유는 신탁회사, 사업은 수익자(진명개발) 측 |
| **지분** | 한 필지를 여러 사람이 **나눠 가진** 몫(513-9의 홍순효 몫) |

**중요.** 「분묘기지권이 있다」고 확정된 것은 아니나, **그럴 수 있는 무덤**이므로 확인·절차 없이 공사하면 위험합니다.

## 6. 일정 안내 (연고자 있음 / 없음 / 분쟁)

**기준.**  
- **D-day** = 그 필지 **토목 착공일**  
- **T0** = 조사 시작일 (보통 착공 **180일 전**을 권장)

### 6-1. 비교표

| 경우 | 대략 소요 | 핵심 |
| --- | :---: | --- |
| **A. 연고자 있음·합의** | 5~6개월 | 합의 + **3개월 전 통보** + 신고 |
| **B. 연고자 없음** | 6~7개월 | **공고 2회**(간격 40일) + 허가 |
| **C. 공고 중 연고자 나타남** | +4~5개월 | 다시 A로 전환 |
| **D. 합의 결렬·소송** | +6~18개월 | 조정·재판 |
| **E. 가처분(공사 금지)** | 불확실 | 그 구간 **착공 정지** |

### 6-2. A. 연고자를 찾은 경우 (유연고)

| 순서 | 내용 |
| :---: | --- |
| 1 | 연고자 확인·면담 |
| 2 | 이장 장소·비용·일정 **합의서** |
| 3 | 이장 예정일 **3개월 이상 전에** 서면으로 알림 |
| 4 | 화성시에 **개장신고**(보통 며칠 내 처리) |
| 5 | 이장·정리 후 그 구간 공사 |

### 6-3. B. 연고자를 못 찾은 경우 (무연고)

| 순서 | 내용 |
| :---: | --- |
| 1 | 조사해도 연고자 없음을 서류로 정리 |
| 2 | **1차 공고**(화성시 장사 공고게시판 등) |
| 3 | **40일 뒤 2차 공고** |
| 4 | 그래도 없으면 **개장허가** 신청 |
| 5 | 허가 후 이장(화장·봉안 등 규칙 준수) · 시청·(국유지는)산림청에 결과 알림 |

### 6-4. 분쟁이 생기면

| 상황 | 결과 |
| --- | --- |
| 공고 중에 연고자가 나타남 | 허가 중단 → 합의·신고로 전환 |
| 합의가 안 됨 | 조정·소송 → 일정 크게 지연 |
| 「분묘기지권」을 주장함 | 지료·이장 소송 가능 → **장기화** |
| 법원에 공사 금지 가처분 | **그 필지 공사 중단** |

**실무 팁.** 세 필지를 한꺼번에 기다리지 말고, 합의된 곳(예: 513-9 소공원)부터 먼저 공사하고 산178 등은 나중에 하는 편이 낫습니다.
