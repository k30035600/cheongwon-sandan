## Ⅲ. 본 지구 시공참여 — 하도급(직접 시공)

근일건설은 희상건설(도급사)과 하도급계약으로 아래 공종을 **직접 시공**합니다. PF **책임준공·면탈(보증 해지)**는 **도급사**가 부담합니다. 상세는 [관계도](관계도_안내.html)를 참조하세요.

| 항목 | 내용 |
| --- | --- |
| **역할** | 하도급사(전문) — 상·하수·철콘·보링·구조물해체·비계 등(01·04~06 해당 공종) |
| **시공참여** | 해당 면허 공종 **직접 수행** · 기술자·장비·현장 조직 투입 |
| **담당 공종(_ka)** | 상·하수 약 18% · 철콘 약 16% · 보링·해체는 부대공에 혼재(관계도 표 참조) |
| **도급한도** | 상·하수 **160억** · 철콘 **144억** · 토공 **245억** · 포장 **90억** 등(2024년 평가, 백만원) — 본 지구 배분액 이내 |
| **근거** | 하도급계약 · 지명원 면허·시공능력 확인서 · 도급사(희상) 현장·품질 관리 |
