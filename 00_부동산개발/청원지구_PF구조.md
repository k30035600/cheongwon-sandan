# 화성 청원지구 — PF·책임준공 핵심 구조

**작성일** 2026. 7. 14. | **작성** 삼아건설(주) | **시행자** 진명개발(주)  
**숫자 SSOT** 청원지구 사업수지분석표(추정) · 책준 입보액은 **협의 가정**(Term Sheet·약정 확정 전)

**한 줄 요약.**  
① **사업 전체**는 자기자본 **240억** + PF 요청 한도 **300억**으로 총사업비 **약 460억**을 조달한다(용지는 자기자본, 용지 외는 PF·잔여 자기자본).  
② **책임준공 입보**는 PF 300억 전부가 아니라 **공사비 PF(협의 가정 100억)** 에만 걸린다. 시공사는 조성공사 **약 139억**을 기한 내 완공하고, 미준공 시에만 그 **100억**을 채무인수한다.

> **읽는 법.** Ⅰ~Ⅱ = 사업수지(전체 자금). Ⅲ~Ⅴ = 책임준공·입보(시공사·대주단). 두 층을 같은 300으로 읽지 말 것.

## Ⅰ. 사업 전체 자금 (사업수지 SSOT)

| 구분 | 금액 | 의미 |
| --- | ---: | --- |
| **총사업비(총비용)** | **약 460억** | 46,027,831,835원 |
| **자기자본** | **240억** | 지정 · 자기자본비율 약 52% |
| **타인자본(차입 소요)** | **약 220억** | 총사업비 − 자기자본 |
| **근저당 실채권(대환)** | **약 32억** | 선순위 확보용 기존채무 대환 |
| **PF 총대출(요청 한도)** | **300억** | 입력 가정 · 기성·결재 **분할 인출** |
| **조성공사비** | **약 139억** | 희상 260707 공급가액 13,901,806,101(부가세 별도) |
| **용지비** | **약 212억** | 토지매입·용역·부대비 등 |

```
[조달]
 자기자본 240억 ──► 주로 용지비(~212억) + 잔여·초기비
 PF 한도 300억 ──► 용지 외 사업비(공사·인허가·부담금·금융 등) 기성·결재 인출
                    (실차입 소요 ~220억 + 대환 ~32억 + 여유)

[비용 약 460억] = 용지 + 조성 + 인허가·부담금 + 관리·판매 + 금융 + 예비비 …
```

**용도 구도(이해용).** 시행사가 자기자본으로 **용지비를 선부담**하면, 이후 **조성공사·인허가·제부담금 등**은 PF 한도(300억) 안에서 기성·결재로 나눠 쓰는 구도가 된다.  
다만 **300억이 전부 소진된다**거나 **총사업비=300억**은 아니다.

## Ⅱ. 지급 vs 보증 — 먼저 구분

| 말 | 뜻 | 누가 |
| --- | --- | --- |
| **지급** | 기성대금을 **실제로 줌** | PF 인출(대주단 대출) + 시행사 **자기자본** |
| **PF 기성 인출** | 대출 한도 안 사업계좌로 돈 인출 | 대주단 → 신탁·자금관리 → 시공사 등 |
| **책임준공 입보** | 미준공 시 **대출을 시공사가 인수** | 시공사 — **지급 통장이 아님** |

- 「입보로 공사비를 준다」 ❌  
- 「입보는 못 끝내면 은행 대출을 떠안는다」 ✅

## Ⅲ. 책임준공·입보 층 (공사비 PF만)

PF **요청 한도 300억** 중, 시공사 책준이 걸리는 것은 **공사비에 연동된 대출분**이다.  
(토지대환·기타·버퍼 등 나머지 PF는 담보·시행사 상환 중심으로 보는 것이 일반적 · 약정으로 확정)

| 구분 | 금액 | 의미 |
| --- | ---: | --- |
| **조성공사비(완공 의무)** | **약 139억** | 기한 내 **사용승인(준공)** 대상 전액 · 기성청구 상한에 해당 |
| **공사비 PF(책준 대상 · 협의 가정)** | **100억** | 이 한도만 기성·결재로 **책준 연계 인출** · **입보액과 정합** |
| **공사비 중 자기자본 등 지급분** | **약 39억** | 139 − 100 · 시행사 자기자본·잔여 조달로 지급 |
| **시공사 책임준공 입보** | **100억** | 미준공 시 위 공사비 PF **채무인수** 한도 |

```
[정상]
 기성청구 최대 ~139억
   ├─ 공사비 PF 인출 최대 100억 ──► 시공사 지급
   └─ 시행사 자기자본 등 ~39억 ──► 시공사 지급
 준공(사용승인) ──► 입보 100억 면탈(해지)

[미준공]
 시공사 ──► 공사비 PF 100억 채무인수(이자·약정 손해 포함 범위는 약정)
```

### 시공사 책임 3가지

1. **물리적** — 조성공사 **약 139억** 기한 내 완공(책준·모범규준 전제의 중단·유치권 제한 등 약정 따름).  
2. **금융적** — 미준공 시에만 **입보 100억** 채무인수.  
3. **소멸** — 기한 내 준공 시 입보 **즉시 면탈**. 이후 PF 상환은 시행사·분양·대환.

## Ⅳ. 한눈에 보는 주체별 부담

| 주체 | 부담 | 핵심 |
| --- | --- | --- |
| **시행사(진명개발)** | 자기자본 **240억** | 용지 선투입 · 공사비 잔여·초기비 · 분양·대환 · 준공 후 PF 상환 |
| **대주단** | PF 한도 **300억**(요청) | 담보·결재·기성 인출 · 그중 **공사비 PF 100억**에 책준 입보 결합(가정) |
| **시공사** | 공사 **~139억** 완공 + (미준공 시) 입보 **100억** | 책임준공 · 채무인수 · 준공 시 면탈 |

## Ⅴ. 예전에 헷갈리던 숫자 (폐기·치환)

| 구 가정(논의 초안) | 현재(사업수지 SSOT + 책준 가정) |
| --- | --- |
| 총사업비 300 = 에쿼티 200 + PF 100 | **총사업비 ~460** = 자기자본 **240** + 차입·PF 구조(**요청 한도 300**) |
| 공사비 150 · 입보 100 | 공사비 **~139** · 입보 **100**(공사비 PF와 정합 · 협의 가정) |
| 「PF 300 = 총사업비」 | ❌ · 300은 **대출 요청 한도** |
| 「입보로 100억 지급」 | ❌ · 입보는 **미준공 시 채무인수** |
| 「200억 담보로 PF 300」 | △ 방향만 · 자기자본은 **선투입**, 담보는 주로 **토지·신탁** |

## Ⅵ. 확정 시 체크 (Term Sheet·LOC·도급)

1. PF **총한도**와 **공사비 PF(책준 대상)** 금액을 약정에 **분리 기재**할 것.  
2. 입보액 = 책준 대상 대출액(현 가정 **100억**) · 채무인수비율·이자·면탈 시점.  
3. 도급액(조성공사)을 수지 **약 139억**과 맞출 것(견적·계약 확정 시 갱신).  
4. 기성 인출 = 검측·결재조건 · 자기자본 투입 순서(용지 선투입) 명기.
