## 5. 추가 산출 — 가능 / 한계

| 항목 | 산출 여부 | 방법 |
|---|:---:|---|
| 토량 수지(절·성·운반 균형) | ✅ 완료 | 공내역 물량 역산(3항) |
| 토질별 절토·운반 용도 집계 | ✅ 완료 | 공내역 분류 집계 |
| 벌개제근 면적·지구비 | ✅ 완료 | 공내역 ↔ 고시면적 |
| 획지 계획고(FH) 표 | ✅ 완료 | 정지계획평면도 판독 |
| 측점별 절·성 단면적→체적(평균단면적법) | ❌ 불가(현 자료) | 횡단면도 OCR 실패 — 아래 |
| 획지별 절·성토 체적(FH−GH) | ⚠ 보류 | DWG 또는 지형 GH 데이터 필요 |

### 측점별 체적 산출(평균단면적법) — OCR 시도 결과

```
V = Σ (A_i + A_{i+1}) / 2 × L  (구간거리)
  A : 측점별 절토·성토 단면적(㎡, 횡단면도 표)
  L : 측점 간 거리(도로종평면도 STA)
```

- EasyOCR(ko+en, 300DPI) 시험 OCR로 횡단면도 5쪽을 판독한 결과, 표의 단면적 숫자가 대부분 `00·OC·0.00` 노이즈로 판독되어 **측점별 단면적 추출 불가**로 확인됐다. 표 글자가 8~10px로 너무 작고 조밀하기 때문이다.
- 독립 검산을 하려면 다음 중 하나가 필요하다.
  ① **CAD 원본(.dwg)** 확보 → 단면적·STA 직접 추출(가장 정확)
  ② 횡단면도 표 영역을 **고배율 크롭 + 수기 입력**으로 디지털화
  ③ 설계사(시우이엔씨) **토적표(수량산출서) 원본** 별도 요청
- 현 단계의 검증은 **3항 토량수지(절·성·운반 균형)**로 갈음한다(공내역 물량 자체가 본 도면의 산출 결과).
